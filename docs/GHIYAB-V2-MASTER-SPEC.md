## 2. اصول غیرقابل‌مذاکره (از الزامات صریح Owner + سند معماری قبلی پروژه)

1. **No Fake Integration** — سرویس متصل‌نشده = `NOT_CONFIGURED`/`BLOCKED`، هرگز شبیه‌سازی نمی‌شود.
2. **No plaintext secrets** — فقط Environment/secure config.
3. **Transaction-safe + Idempotent** برای همهٔ عملیات مالی.
4. **Everything Auditable** — هر تغییر مهم قابل ردیابی و برگشت.
5. **Least Privilege** — حتی AI و حتی Owner-agentها از Approval Layer برای عملیات حساس عبور می‌کنند.
6. **کد سالم بدون دلیل مستند حذف نمی‌شود** — Refactor یعنی جابه‌جایی/بهبود، نه دور ریختن بی‌دلیل.
7. **Dependency minimalism** — افزودن کتابخانه فقط با توجیه مشخص.
8. **PostgreSQL-ready بودن حتی روی SQLite** — لایهٔ Repository مستقل از دیتابیس.
