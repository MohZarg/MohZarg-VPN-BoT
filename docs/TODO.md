## 🟠 مهم — قبل از Phase مربوطه

4. **سطوح کاربری (User Levels) و Reseller:** معیار ورود به هر سطح، درصد تخفیف هر سطح، و تفاوت Reseller با نمایندهٔ فعلی (۱۰٪ ثابت) چیست؟
